# Docs

This folder contains **project documentation** that doesn’t need to live at the repo root.

- `docs/ai/`: AI assistant / agent instructions
- `docs/bridge/`: Bridge setup and quick-start docs
- `docs/database/`: Database runbooks, hardening notes, and backup guidance
- `docs/migrations/`: Schema / feature migration guides

Cursor-generated plans and implementation summaries live in `cursor-plans/`.
