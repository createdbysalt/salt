# Salt Core Brand System

This folder is the source of truth for Salt Core voice, terminology, and copy.

## Brand Architecture

**Salt Core** has a dual-brand system:

1. **Salt Core** (this product) — The technical studio operating system. Voice is confident, clear, systems-focused. Speaks to developers and designers building studios.
2. **SALT Studio** (CreatedBySalt.com) — Gabriella's client-facing creative studio. Voice is warm, thoughtful, mission-driven. Speaks to end clients (churches, studios, startups).
3. **The Bridge** — The product connecting the two. Professional, clear, white-labelable client portal.

This folder contains guidelines for **Salt Core** (the product). SALT Studio has separate brand guidelines.

## Structure

- **`bible/`**: Protected brand identity files (don't edit without explicit approval).
  - `salt_core_identity.md` — Complete brand identity and positioning
  - `salt_core_voice_bible.md` — Complete voice and tone guidelines
  - `salt_studio_identity.md` — SALT Studio's separate brand identity (for reference)
- **`brand-terms.md`**: Product names, UI terms, capitalization rules.
- **`copy-snippets.md`**: Pre-approved button labels, errors, empty states.
- **`email-templates/`**: Canonical email copy blocks.

## How to use

1. **For identity and positioning**, consult `bible/salt_core_identity.md` first.
2. **For voice and tone decisions**, consult `bible/salt_core_voice_bible.md`.
3. **For quick lookups** (product names, button labels), use the reference docs in this folder.
4. **Before adding new patterns**, update the relevant file here and ensure it aligns with the identity and voice bible.
