## What Salt Core Is (And Isn't)

### We Are:
- **The complete studio operating system** — boilerplate, client portal, AI intelligence, and business infrastructure
- **Proof that works** — the same system powering SALT Studio's $10k+ client projects
- **A professional accelerator** — for people who take their work seriously and want to charge accordingly
- **Opinionated about foundations** — so you can be opinionated about implementation

### We Are Not:
- **A learn-to-code platform** — we assume capability, whether from traditional development or AI-native workflows
- **A freelancer marketplace** — we build studios, not gig workers
- **A no-code tool** — we give you production code you own and can modify
- **One-size-fits-all** — we're opinionated because generic doesn't work

## The Product Ecosystem

Salt Core isn't just a boilerplate — it's a complete studio operating system with three interconnected components:

### 1. The Core (Infrastructure)
The Next.js foundation with auth, billing, email, database, and deployment configured.

**What it solves:** "I'm spending 40 hours on setup instead of building the actual product."

### 2. The Intelligence Layer (Strategy)
Multi-agent AI that generates competitor audits, brand positioning, and AEO (Answer Engine Optimization) strategies.

**What it solves:** "I can build websites but I'm competing on price, not strategic value."

### 3. The Bridge (Client Portal)
The professional command center where clients manage projects, view analytics, request changes, and see their brand assets.

**What it solves:** "My clients don't see me as professional because I'm communicating via Slack and email like a freelancer."

**Together they solve:** "I want to run a studio that charges $10k-50k per project and builds recurring revenue, but I don't have agency infrastructure."

## The 6-Layer Architecture

Salt Core is built on a **6-Layer Operating System** that defines how every feature and service integrates:

1. **Infrastructure (The Engine)** — Next.js foundation, auth, database, deployment
2. **Intelligence (The Brain)** — Multi-agent AI for strategy generation and market research
3. **Operations (The Flow)** — Client onboarding, contracts, pitch decks, project management
4. **Community (The Network)** — Peer reviews, pricing validation, fractional collaboration
5. **Velocity (The Maintenance)** — Monthly updates, security patches, new features
6. **Finance (The Fuel)** — Billing, MRR tracking, growth retainers, profitability analytics

All development and strategic work must align with one of these layers.

## Decision Framework

When creating anything for Salt Core (feature, content, marketing, UI), ask:

### 1. Does this advance one of the 6 layers?
If it doesn't map to Infrastructure, Intelligence, Operations, Community, Velocity, or Finance — it's not Salt Core.

### 2. Does this work for BOTH audiences?
If traditional developers would roll their eyes OR designer-developers would feel excluded — revise it.

### 3. Is this production-quality?
If it's not good enough for SALT Studio to use with paying clients — it's not ready.

### 4. Does this create business leverage?
If it doesn't help studio owners ship faster, charge more, or build recurring revenue — question if it belongs.

### 5. Would Gabriella use this?
Salt Core is Gabriella's system. If she wouldn't use a feature or trust that copy, neither would customers.

If yes to all five, proceed. If no to any, return to the principles.
