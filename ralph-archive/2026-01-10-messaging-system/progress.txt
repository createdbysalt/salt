## Codebase Patterns

- Use `createAdminClient()` from `libs/supabase/admin.ts` for admin operations (user creation, bypassing RLS)
- Supabase triggers auto-create profiles and studios on new user signup via `handle_new_user()` function
- Studio members are linked via `studio_members` table with roles: owner, admin, member, viewer
- Client users are linked via `client_users` table with status field for activation
- Billing interval mapping: UI uses "month"/"year" but PRICE_IDS keys use "monthly"/"annual" - always use intervalSuffix = interval === "month" ? "monthly" : "annual"
- Dev-login page at `/dev-login` allows password auth for test users (test-studio@saltcore.dev, test-client@saltcore.dev)
- ActionResponse error handling: Use `else { setError((result as ErrorResponse).message); }` for proper TypeScript narrowing
- Use `import * as crypto from "crypto"` for Node.js crypto module in server actions
- Token generation: `crypto.randomBytes(32).toString("hex")` for 256-bit secure tokens
- Token hashing: `crypto.createHash("sha256").update(rawToken).digest("hex")` before storage
